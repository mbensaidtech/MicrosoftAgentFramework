# Expense policy

Use this skill to answer questions about business expenses.

1. Read the `references/limits.md` resource: it holds the current spending limits. Never guess an amount.
2. Give the limit that matches the question, with its unit and currency.
3. If the question is about filing an expense report, explain the steps below.

## Filing an expense report

- File the report within 30 days of the end of the trip, in the finance portal.
- Attach every receipt over 25 EUR.
- Expenses over a limit need the written approval of your manager.
