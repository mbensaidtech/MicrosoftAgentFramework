# IT support

1. VPN does not connect: restart the VPN client, then open a ticket in the category NET-42 if it still fails.
2. Password expired or locked: reset it on the self-service portal; after three failed resets, call the service desk.
3. Lost laptop or phone: report it within one hour with a ticket in the category SEC-11, so that the device can be wiped.
